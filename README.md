# 红色甘农

> 两条路，一张纸：红军走过的甘肃，和甘农人走了八十年的路，放在同一张纸上读。

甘肃农业大学“第五届红色网页设计大赛”参赛作品。

## 作品简介

《红色甘农》将红军长征在甘肃的足迹（1934—1936）与甘肃农业大学八十年办学历程（1946—2026）并置对照，彰显认准方向、艰苦奋斗、服务人民的红色精神。

作品采用 HTML、CSS、JavaScript 三文件分离的静态架构，兼容 Edge 90 及以上版本。核心功能包括长征路线图、校史时间轴、翻转卡片、寄语墙和红色答题。设计上仿照一份红色校报，主色为中国红与金色。

## 红色主题

| 长征路（1934—1936）                        | 甘农路（1946—2026）                                  |
| ------------------------------------------ | ---------------------------------------------------- |
| 南梁、迭部、腊子口、哈达铺、会宁、河西走廊 | 小西湖创校、西迁黄羊镇、迁回兰州、荒滩建校、八十周年 |

两段历史处境不同，做事的方式却很接近：先认准方向，再一砖一瓦往前挪。

## 功能

- **首页**：仿校报刊头、头条、目录和印章，数字滚动统计
- **长征路**：可点击的路线示意图，与时间轴、上一站/下一站联动
- **甘农路**：可展开的八十年校史时间轴
- **田间答卷**：成果表点选查看细节，毕业生去向进度条
- **精神传承**：四张双面翻转卡片（方向、苦干、汇合、为民），以及寄语墙
- **红色答题**：8 道题，带解析与得分

## 图片说明

- 页面中的插图为原创矢量图，位于 `images/`。
- 如需使用网络图片，打开 `js/main.js` 末尾的 `PHOTOS` 配置，填写图片地址和出处：

```js
var PHOTOS = {
  journey: { src: '图片地址', credit: '出处' },
  campus:  { src: '', credit: '' },
  field:   { src: '', credit: '' }
};
```

页面会在图片下方自动标注“图片来源：出处”；图片加载失败时会自动换回原创插图。请选择可确认出处、允许使用的图片，并如实标注来源。

## 兼容性

按 Edge 90 及以上版本编写，已避免使用较新的 CSS 与 JS 特性。提交和部署后建议在 Edge 中把每个栏目都点一遍，确认显示和交互正常。
